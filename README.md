# RoachGuide — SEO Lab Version 1

This is a deliberately simple static website for learning SEO.

## Before publishing

1. Replace every occurrence of `https://YOUR-SITE.example` with the actual site URL.
2. Review and fact-check the pest-control content.
3. Add authoritative references to the main article.
4. Add a real contact/privacy setup before treating this as a production site.
5. Validate HTML, mobile usability and structured data.
6. Deploy to your chosen free static host.
7. Add the site to Google Search Console.
8. Submit `/sitemap.xml`.

## SEO experiment

Primary target:
- effective cockroach killing remedy

Secondary themes:
- how to kill cockroaches
- cockroach control at home
- cockroach gel bait
- cockroach spray vs bait
- how to prevent cockroaches
- signs of cockroach infestation

## What to measure

Record weekly:
- impressions
- clicks
- CTR
- average position
- indexed pages
- queries generating impressions
- top landing pages

Do not change many variables simultaneously. Treat each content/technical change as an experiment.

## Important

This is educational content, not professional pest-control advice. Pesticides should be used only according to their labels and applicable local requirements.


## Version 1.1 SEO audit changes

The first audit identified a crowded SERP around:
- how to get rid of cockroaches
- cockroach control in Indian homes
- gel bait vs spray

Version 1.1 differentiates the site by:
- using integrated pest management as the organizing framework;
- adding a method-selection section rather than only a generic list;
- explicitly addressing common overclaims and limitations;
- citing authoritative UC IPM, University of Minnesota Extension and EPA guidance;
- keeping the interactive decision tool;
- avoiding unsupported claims such as guaranteed permanent elimination or universal effectiveness percentages.

Next experiment: deploy only after replacing `YOUR-SITE.example`, then measure indexing and query impressions before making further content changes.
